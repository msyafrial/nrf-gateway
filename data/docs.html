Struktur Data Telemetri Beacon (Bitmask Dynamic Protocol v2)

Compact Binary v2

Gateway memancarkan paket telemetri biner hemat bandwidth dengan bitmask self-describing. Field yang dikirim dapat dicentang bebas di Web UI tanpa merusak script parser klien.

Urutan Field Bit Flag Ukuran Tipe Data Keterangan
Header Mask 0x80 1 Byte uint8 Penanda protokol dinamis v2 + kombinasi bit aktif
1. Proximity UUID 0x01 16 Byte hex 128-bit Raw Proximity UUID iBeacon
2. Major ID 0x02 2 Byte uint16 BE ID grup / lantai / lokasi (0 - 65535)
3. Minor ID 0x04 2 Byte uint16 BE ID unik unit aset / tag (0 - 65535)
4. RSSI 0x08 1 Byte int8 Kekuatan sinyal radio fisik diterima (dBm)
5. Battery 0x10 1 Byte uint8 Kapasitas baterai beacon (0 - 100%)
6. Timestamp 0x20 4 Byte uint32 BE Unix Epoch detik sinkronisasi NTP / uptime detik
QoS 1 Delivery Guaranteed: Broker wajib mengembalikan PUBACK. Sangat disarankan untuk keandalan data pada jaringan kabel/LAN.
QoS 0 Fire & Forget: Transmisi instan tanpa tunggu konfirmasi outbox. Optimal untuk koneksi seluler berkuota / kepadatan >500 beacon/detik.
