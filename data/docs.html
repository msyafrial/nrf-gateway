Struktur Data Telemetri Beacon

application/json

Gateway memancarkan paket data hasil pemindaian BLE iBeacon dalam bentuk JSON Array pada topik data broker MQTT.

Field Tipe Contoh Keterangan
mac string AC:23:3F:A1:B2:C3 Alamat MAC fisik hardware beacon BLE
uuid string FDA50693-A4E2-4FB1... Proximity UUID 128-bit iBeacon
major uint16 10001 Identifier grup/lokasi (0 - 65535)
minor uint16 102 Identifier unit individual (0 - 65535)
rssi int8 -68 Kekuatan sinyal radio diterima (dBm)
tx_power int8 -59 Kalibrasi daya pancar pada jarak 1 meter
distance float 2.45 Estimasi jarak kalkulasi log-distance (meter)
batt_pct uint8 94 Estimasi kapasitas baterai beacon (%)
timestamp int64 1729792000 Unix Epoch timestamp detik (Sinkronisasi NTP)
QoS 1 Delivery Guaranteed: Broker wajib mengembalikan PUBACK. Sangat disarankan untuk keandalan data pada jaringan kabel/LAN.
QoS 0 Fire & Forget: Transmisi instan tanpa tunggu konfirmasi outbox. Optimal untuk koneksi seluler berkuota / kepadatan >500 beacon/detik.
